نواب گلد — نسخه کامل

ویژگی‌های این نسخه:
- قیمت بازار از Tala.ir WebSocket
- چرخه تازه‌سازی اتصال قیمت هر ۵ دقیقه
- اگر اتصال زنده قطع شود، تلاش خودکار برای اتصال مجدد
- قیمت ۱۸ عیار از geram18
- بدون منبع جایگزین قیمت
- فرمول مشتری: وزن × نرخ روز طلای ۱۸ × 1.14 × 1.07
- ۱۰٪ مالیات حذف شده
- قیمت از زیر کارت محصول حذف شده و در صفحه مشاهده محصول نمایش داده می‌شود
- پنل مدیریت با رمز 0000
- عکس‌های محصولات حفظ شده‌اند
- پشتیبانی، بازدیدکننده و سفارش در پنل موجود است
- سرور روی 0.0.0.0 اجرا می‌شود تا LAN و تونل عمومی بتوانند به آن دسترسی داشته باشند

اجرای روی مک:
1) Terminal را باز کن.
2) وارد پوشه navab-gold شو.
3) npm install
4) npm start
5) در Chrome مک: http://localhost:3000
6) پنل: http://localhost:3000/admin.html
7) رمز پنل: 0000

برای لینک قابل گذاشتن در Bio اینستاگرام:
این پروژه دامنه یا Google نمی‌خواهد، اما برای لینک عمومی باید یک تونل/هاست داشته باشی.
فایل start-public.sh برای Cloudflare Quick Tunnel آماده شده است.
اگر cloudflared نصب باشد:
./start-public.sh
لینکی که cloudflared چاپ می‌کند را می‌توانی در Bio اینستاگرام بگذاری.
نکته: این لینک موقت است و تا وقتی Mac و Terminal روشن و اسکریپت در حال اجراست کار می‌کند.
برای لینک دائمی، بعداً باید یک سرویس هاست همیشه‌روشن انتخاب کنیم؛ دامنه شخصی اجباری نیست.
