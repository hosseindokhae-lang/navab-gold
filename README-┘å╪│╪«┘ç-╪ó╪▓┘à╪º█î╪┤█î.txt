نسخه آزمایشی نواب گلد — اتصال قیمت به Tala.ir
================================================

این نسخه دو حالت دارد:

1) preview.html
   - با دوبار کلیک مستقیم در Chrome باز می‌شود.
   - قیمت‌های داخل آن همان Snapshot داده‌ای هستند که کاربر از WebSocket تالا فرستاده است.
   - برای نمایش و تست ظاهر بازار و محاسبه‌گر است و سفارش/پشتیبانی سروری در این حالت فعال نیست.

2) نسخه اصلی navab-gold/
   - اجرای کامل با Node.js.
   - منبع قیمت فقط Tala.ir WebSocket است.
   - برای اتصال زنده، بسته ws لازم است.

اجرای نسخه اصلی:
----------------
1. Node.js نسخه 20 یا بالاتر نصب باشد.
2. وارد پوشه navab-gold شوید.
3. اجرا کنید:
   npm install
   npm start
4. مرورگر:
   http://localhost:3000

اتصال زنده تالا:
----------------
سرور به صورت پیش‌فرض به این WebSocket وصل می‌شود:
wss://web1.tala.ir/ws/

برای تغییر آدرس:
TALA_WS_URL=wss://web1.tala.ir/ws/ npm start

اگر ws نصب نباشد:
- سرور همچنان بالا می‌آید.
- قیمت‌ها از Snapshot داده‌ای که در اختیار پروژه قرار گرفته نمایش داده می‌شوند.
- برای قیمت زنده حتماً npm install را اجرا کنید.

قیمت‌ها:
---------
کلیدهای اصلی:
geram18 = طلای 18 عیار
geram21 = طلای 21 عیار
geram22 = طلای 22 عیار
geram735 / geram740 / geram995 / geram999 = عیارهای دیگر
sekkejad = سکه امامی
sekkegad = سکه قدیم
sekkenim = نیم سکه
sekkerob = ربع سکه
sekkegrm = سکه گرمی
sekke-arzesh = ارزش سکه
sekke-hobab = حباب سکه
ounce = اونس جهانی
usd / eur / gbp ... = ارزها
USDT_IRT = تتر
BTC_USDT / ETH_USDT = رمزارزها
ENERGY_BRENT = نفت برنت

فرمول قیمت:
------------
وزن × نرخ طلای 18 عیار
× (1 + اجرت 14٪)
× (1 + سود 7٪)
× (1 + مالیات 10٪)

به مشتری فقط قیمت نهایی نمایش داده می‌شود.

امنیت:
-------
رمز پنل اصلی از متغیر محیطی ADMIN_PASSWORD خوانده می‌شود.
اگر این متغیر تنظیم نشده باشد، مقدار پیش‌فرض فعلی پروژه:
0000

رمز پیش‌فرض این نسخه: 0000
برای استفاده واقعی، بهتر است ADMIN_PASSWORD را تغییر دهید.
